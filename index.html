How a workflow works

Three pieces create a useful automation.

1
TriggerSomething happens, like a new lead arriving.
2
Condition (optional)Check a rule, such as the lead source.
3
ActionQueue a task or send a message through a connected service.
This prototype saves workflow definitions but does not run background jobs or send messages yet.
